# LogiTalk
Це програма-чат: Перед вами код для комп'ютерного додатка «Logi Talk Pro» — звичайного чату для листування (як Telegram або Viber).

Гарний зовнішній вигляд: Дисплей і всі кнопки створені за допомогою бібліотеки CustomTkinter — вона робить інтерфейс сучасним, з круглими кутами та приємними кольорами.

Працює через інтернет (сокети): Програма вміє підключатися до сервера за адресою localhost:8080, щоб надсилати й отримувати повідомлення.

Не зависає під час роботи: Прийом нових повідомлень відбувається в «окремому фоновому режимі» (у паралельному потоці), тому вікно програми не заліпає, поки очікує відповіді від сервера.

Власний формат секретних записок: Програма та сервер «спілкуються» за допомогою спеціальних команд через символ @. Наприклад, додаток каже серверу: це ТЕКСТ @ від ІВАНА @ "Привіт".
